# تعاونی آسمان شهر هلیا

سامانه مدیریت مشتریان، واریزی‌ها و اعلام واریزی — تک‌صفحه‌ای، ریسپانسیو، با تاریخ شمسی و ساعت تهران.

## نصب و اجرا ب

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

## ساخت نسخه‌ی نهایی (Production Build)

```bash
npm run build
npm run preview
```

فایل‌های نهایی در پوشه‌ی `dist` ساخته می‌شوند و برای آپلود روی هر هاست ساده‌ای آماده‌اند.

## ساختار پوشه‌ها

```
aseman-shahr-helia/
├── index.html
├── package.json
├── vite.config.js
├── src/
│   ├── main.jsx              نقطه‌ی ورود React
│   ├── App.jsx                کامپوننت اصلی و منطق برنامه
│   ├── styles.css             تمام استایل‌ها
│   ├── components/
│   │   ├── Header.jsx         سربرگ + ساعت تهران + تاریخ شمسی
│   │   ├── Footer.jsx         فوتر + دکمه‌های Export/Import
│   │   ├── BackgroundDecor.jsx   افکت‌های پس‌زمینه
│   │   ├── Icons.jsx          مجموعه آیکون‌های SVG (شامل لوگو)
│   │   ├── Shared.jsx         Section، Field، JalaliDateFields
│   │   ├── CustomerCards.jsx  کارت مشتری / واریزی / اعلام واریزی
│   │   ├── CustomerModal.jsx  فرم اضافه/ویرایش مشتری
│   │   ├── DepositModal.jsx   فرم اضافه/ویرایش واریزی
│   │   ├── NoticeModal.jsx    فرم اضافه/ویرایش اعلام واریزی
│   │   ├── ModalShell.jsx     قالب مودال با بلور پس‌زمینه
│   │   └── Toast.jsx          پیام‌های موفقیت/خطا
│   └── utils/
│       ├── dateUtils.js       تبدیل شمسی/میلادی، ساعت تهران، محاسبه امتیاز
│       └── storage.js         ذخیره‌سازی محلی + Export/Import JSON
```

## داده‌ها و پشتیبان‌گیری

- تمام اطلاعات به‌صورت خودکار در `localStorage` مرورگر شما ذخیره می‌شود (نیازی به سرور نیست).
- با دکمه‌ی **«خروجی گرفتن (Export)»** در پایین صفحه، یک فایل JSON از تمام اطلاعات دانلود می‌شود که می‌توانید هرجا بخواهید (فلش، ایمیل، گوگل‌درایو) نگه دارید.
- با دکمه‌ی **«وارد کردن (Import)»** می‌توانید یک فایل پشتیبان قبلی را انتخاب کنید؛ اطلاعات آن با داده‌های فعلی شما ادغام می‌شود (رکوردهای تکراری بر اساس شناسه‌ی داخلی به‌روزرسانی می‌شوند، رکوردهای جدید اضافه می‌شوند).

## نکته درباره‌ی تاریخ

امتیاز هر مشتری بر اساس فاصله‌ی روزهای گذشته از **تاریخ دستی واریزی** تا لحظه‌ی حال محاسبه می‌شود؛ این محاسبه کاملاً محلی و مستقل از تنظیمات ساعت سیستم یا اتصال اینترنت انجام می‌شود.

## لوگو

لوگوی فعلی یک نماد ساده‌ی SVG موقت است (در `src/components/Icons.jsx`، تابع `Icon.logo`). هروقت لوگوی نهایی آماده شد، کافی است در همان‌جا با تصویر یا SVG جدید جایگزین شود.
