# شرکت تعاونی آسمان شهر هلیا

سامانه مدیریت مشتریان، واریزی‌ها و ابلاغیه‌ها — با تاریخ شمسی، ساعت تهران، و اکنون به‌صورت اپلیکیشن دسکتاپ ویندوز (سازگار با ویندوز ۷).

## دو معیار حیاتی که همیشه رعایت می‌شوند

**۱) بک‌آپ JSON در چند جا:**
دکمه‌های «خروجی گرفتن» و «وارد کردن» در پایین صفحه، در نسخه‌ی دسکتاپ مستقیماً پنجره‌ی بومی ویندوز را باز می‌کنند تا بتوانید فایل پشتیبان را در هر مسیر دلخواه (فلش، هارد دیگر، پوشه‌ی ابری) ذخیره یا از آن‌جا بارگذاری کنید. جدا از این، برنامه یک فایل اصلی مستقل هم دارد (`data.json` در پوشه‌ی داده‌های کاربر ویندوز) که با بک‌آپ‌های شما کاملاً جداست؛ یعنی اگر فایل اصلی مشکلی پیدا کند، بک‌آپ‌هایی که در جاهای دیگر گرفته‌اید دست‌نخورده باقی می‌مانند.

**۲) تاریخ همیشه درست، چه آنلاین چه آفلاین، چه ساعت سیستم خراب باشد چه نباشد:**
- وقتی اینترنت هست: برنامه با یک درخواست HTTPS به چند سرور معتبر (کلودفلر، گوگل، مایکروسافت، گیت‌هاب)، ساعت واقعی را می‌گیرد.
- وقتی اینترنت نیست: به‌جای اعتماد به ساعت سیستم (که ممکن است دستی تغییر کرده باشد)، از «مدت روشن‌بودن سیستم از آخرین ری‌استارت» (که با تغییر تاریخ دستی خراب نمی‌شود) استفاده می‌کند تا از آخرین لحظه‌ی تأییدشده تا الان را دقیق حساب کند.
- به‌عنوان آخرین خط دفاعی: برنامه هیچ‌وقت اجازه نمی‌دهد «الان» از آخرین زمان معتبر ثبت‌شده عقب‌تر برود — حتی اگر سیستم ری‌استارت شده و ساعتش هم خراب باشد.

## دانلود و اجرا روی ویندوز (بدون نصب Node)

اگر فایل `AsemanShahrHelia-win32-x64-portable.zip` را دریافت کرده‌اید:
1. فایل zip را در هر پوشه‌ای اکسترکت (استخراج) کنید.
2. وارد پوشه‌ی `win-unpacked` شوید و روی `AsemanShahrHelia.exe` دوبار کلیک کنید.
3. همین! نیازی به نصب یا اینترنت برای اجرا نیست (فقط برای همگام‌سازی تاریخ، وصل‌بودن اینترنت مفید است، نه ضروری).

این نسخه «پرتابل» است: می‌توانید کل پوشه را روی فلش بگذارید و روی هر ویندوز ۷ به بالایی اجرا کنید، بدون نصب.

## سازگاری با ویندوز ۷ قدیمی و بدون آپدیت (خیلی مهم)

مهم‌ترین مشکلی که یک برنامه‌ی Electron/جدید ممکن است روی یک **ویندوز ۷ به‌روزنشده** با آن روبه‌رو شود، نبودِ یک فایل سیستمی به‌نام Universal C Runtime (UCRT) است — بدون آن، برنامه اصلاً باز نمی‌شود و خطای «DLL گم‌شده» می‌دهد. این مشکل به دو شکل پیشگیرانه حل شده:

1. **نصاب (exe):** خودش قبل از نصب برنامه، بررسی می‌کند این فایل روی سیستم هست یا نه؛ اگر نبود، بسته‌ی رسمی Microsoft Visual C++ Redistributable (که شامل UCRT است) را خودکار و بی‌صدا از سایت مایکروسافت دانلود و نصب می‌کند — کاربر هیچ کاری لازم نیست بکند (فقط برای همین یک بار، هنگام نصب، نیاز به اینترنت است).
2. **نسخه‌ی پرتابل (zip):** چون نصاب ندارد نمی‌تواند این کار را خودکار انجام دهد، پس یک فایل کمکی هم کنارش گذاشته شده به اسم **«اگر-برنامه-باز-نشد-این-را-اجرا-کنید.bat»** — اگر با دابل‌کلیک روی exe برنامه باز نشد، فقط همین فایل bat را یک‌بار اجرا کنید (نیاز به اینترنت دارد)، مشکل حل می‌شود و از آن به بعد برنامه به‌صورت کامل آفلاین هم باز می‌شود.

اگر سیستم ویندوز ۷ هدف اصلاً هیچ‌وقت اینترنت ندارد، پیشنهاد می‌شود همان یک‌بار (روی هر سیستم دیگری) فایل زیر را دانلود کنید و با فلش روی آن سیستم منتقل و نصب کنید:
`https://aka.ms/vs/17/release/vc_redist.x64.exe`

بعد از این یک نصب یک‌باره، برنامه دیگر برای هیچ‌کدام از قابلیت‌هایش (حتی بخش زمان) نیازی به اینترنت ندارد.

## ساخت نصاب رسمی (exe نصب‌شونده) از طریق گیت‌هاب
چون ساخت نصاب ویندوزی امضاشده از سیستم لینوکسی امکان‌پذیر نیست (نیاز به Wine دارد)، یک ورک‌فلوی گیت‌هاب اکشن اضافه شده (`.github/workflows/build-windows.yml`) که روی یک رانر واقعی ویندوزی اجرا می‌شود:
1. هر بار که به شاخه‌ی `main` پوش کنید (یا از تب Actions دستی اجرا کنید)، این ورک‌فلو خودکار اجرا می‌شود.
2. نتیجه (هم نصاب `.exe` و هم نسخه‌ی `.zip` پرتابل) به‌عنوان Artifact در تب Actions همان اجرا قابل دانلود است.

## توسعه و ساخت دستی (برای برنامه‌نویس)

```bash
npm install

# اجرای نسخه‌ی وب برای توسعه
npm run dev

# ساخت نسخه‌ی دسکتاپ و اجرای مستقیم آن (روی ویندوز/مک/لینوکس)
npm run electron:start

# ساخت نصاب/پرتابل ویندوزی (روی ویندوز اجرا کنید تا Wine لازم نباشد)
npm run electron:dist
```

نسخه‌ی Electron عمداً روی `22.3.27` قفل شده، چون آخرین نسخه‌ای است که هنوز از ویندوز ۷ پشتیبانی می‌کند (نسخه‌های ۲۳ به بعد این پشتیبانی را حذف کرده‌اند).

## ساخت نسخه‌ی وب (GitHub Pages)

```bash
npm run build
```

## داده‌ها و پشتیبان‌گیری

- **نسخه‌ی دسکتاپ:** فایل اصلی در `%APPDATA%\aseman-shahr-helia\data.json` ذخیره می‌شود (مستقل از مرورگر).
- با دکمه‌ی «خروجی گرفتن» یک نسخه‌ی اضافه هر جا که بخواهید ذخیره کنید.
- با دکمه‌ی «وارد کردن» یک بک‌آپ قبلی را انتخاب کنید؛ اطلاعاتش با داده‌های فعلی ادغام می‌شود (رکوردهای هم‌شناسه به‌روز، رکوردهای جدید اضافه).
